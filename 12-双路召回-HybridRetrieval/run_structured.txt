需求：参考支付模块 P0 级别的用例，生成一条大额支付需要短信验证的用例

━━ SQL 路（LLM 生成查询，吃结构化字段）
  SELECT id, module, name
FROM test_cases
WHERE module = '支付'
  AND priority = 'P0'
  AND (name LIKE '%大额%' OR description LIKE '%大额%'
       OR name LIKE '%短信%' OR description LIKE '%短信%'
       OR name LIKE '%验证%' OR description LIKE '%验证%'
       OR name LIKE '%限额%' OR description LIKE '%限额%')
LIMIT 4;
