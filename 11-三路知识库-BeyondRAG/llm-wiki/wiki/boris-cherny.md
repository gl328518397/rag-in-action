# Boris Cherny

[[claude-code]] 的技术负责人。

在 X 上回复网友时解释了 Claude Code 放弃 RAG 的决定：早期版本用过 RAG 加本地向量库，但很快发现 [[agentic-search]] 总体上效果更好、更简单，且没有 RAG 在 security、privacy、staleness、reliability 四个方面的问题。
