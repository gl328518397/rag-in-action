# Token Economics（token 经济学）

看待 token 消耗的经济视角：token 不是单纯的成本，而是**可以购买正确性的原料**。这一提法出自 source 03 读书笔记，是笔记作者对下面一组数字的经济学解读。

## 三个数字（据 Anthropic 工程博客，经读书笔记二手转述）

- agent 任务的 token 消耗约是普通聊天的 **4 倍**
- 多代理系统约是普通聊天的 **15 倍**
- token 用量单独解释了 **80%** 的效果差异

注意：以上均为读书笔记对 Anthropic 工程博客的转述，非博客原文，故本页 confidence 为 medium；其中"80% 效果差异"是转述的强论断，引用时应保留这一不确定性。

## 与知识库维护经济学的关联（编者推断）

[[bookkeeping-cost]] 从成本侧解释知识库维护为何失败（bookkeeping 成本过高）；本页从收益侧解释 token 投入为何值得（购买正确性）。两者同属成本/收益视角，此关联为本 wiki 的推断，两份原文均未直接建立。

在 [[context-engineering]] 的语境下，这一视角回答的是"为什么值得认真决定 context 里放什么"。
